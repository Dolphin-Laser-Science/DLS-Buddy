## Named methods and relations

Standard, named techniques used in the code. Not always tied to a single paper
in-source; listed so a forker can find where each lives.

| Method / relation | Where used | Note |
|---|---|---|
| **Stokes–Einstein** relation | `physics/constants.py` (`stokes_einstein_rh`) | `Rh = k_B T / (6πηD)` (Berne & Pecora 2000; Chu 1991 does not print it) |
| **Siegert** relation | `analysis/dls/` (cumulants, exponentials, distributions); `analysis/utilities.py` (`generate_synthetic_correlogram`); `parsers/base_parser.py` (`apply_data_form`, `g1` branch) | `g₂−1 = β\|g₁\|²` (Chu 1991; orig. Siegert 1943) |
| **Zimm / Berry / Debye** plots | `analysis/sls.py` (`zimm_analysis`, `debye_analysis`) | Berry = √-ordinate variant for high `qRg` |
| **Guinier** plot | `analysis/sls.py` (`guinier_analysis`) | ln(ΔR) vs q²; Rg from slope (Guinier & Fournet 1955) |
| **Kohlrausch–Williams–Watts (KWW)** | `analysis/dls/exponentials.py` (`fit_kww`) | stretched exponential |
| **Tikhonov regularization** | `analysis/dls/distributions.py` (CONTIN, `fit_contin`) | 2nd-difference operator; α by robust GCV (the default), L-curve corner or F-test |
| **Non-negative least squares (NNLS)** | `analysis/dls/distributions.py` (`fit_nnls`) | `scipy.optimize.nnls` |
| **Freedman–Diaconis** rule | `analysis/trace_analysis.py` (`_freedman_diaconis_bins`) | histogram bin width |
| **Sturges'** rule | `analysis/trace_analysis.py` (`_sturges_bins`) | histogram bin fallback |
| **Augmented Dickey–Fuller (ADF)** test | `analysis/trace_analysis.py` (`test_stationarity_adf`) | stationarity (`statsmodels`) |
| **HC3 heteroscedasticity-consistent SE** | `analysis/uncertainty.py` (`_hc3_cov`) | robust regression covariance (MacKinnon & White 1985; Long & Ervin 2000) |
| **Delta method (1st-order propagation)** | `analysis/uncertainty.py` (`propagate`, `ratio_se`, `power_law_se`) | `Var(f)=JᵀΣJ` (GUM/JCGM 100:2008; Bevington & Robinson 2003) |
